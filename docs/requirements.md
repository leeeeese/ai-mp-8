# 요건 정리 (mockup 데이터 생성 참고용)

난이도별 요건 목록. 원본 캡처 이미지 기반이며, 워터마크로 흐릿한 부분은 문맥으로 보정함.

---

## 난이도 상

### 상-1. 유선+무선 결합상품 A를 무선+무선만으로도 결합 가능하도록 변경

| 구분 | 내용 |
|---|---|
| As-Is | 유선서비스 + 무선서비스 ≤ 5회선에 한해 가입 가능 |
| To-Be | 무선서비스 + 무선서비스 ≤ 5회선 **또는** 유선서비스 + 무선서비스 ≤ 5회선 모두 가입 가능. 유선서비스 미존재 시 상품명 **B**로 노출 |

### 상-2. 요금제 개편에 따른 연령별 혜택 상품 신규 개발

| 구분 | 내용 |
|---|---|
| As-Is | 각 요금상품 기준으로 연령별 가입 가능한 상품을 제한 |
| To-Be | 요금별 가입 가능 연령은 제한(만 19세 미만 / 만 14세 미만 / 만 65세 이상)하되, 명의당 1회선으로 연령별 혜택을 부가상품으로 정의하여 제한 |

**예시:** 만 25세 이용자가 3회선을 사용 중인 경우

- 기존: 3회선 모두 청년 대상 요금제에 가입함으로써 혜택 수령
- 변경 후: 3회선 모두 가입 가능 요금제에 가입하되, '청년 혜택' 상품은 1개 회선에 대해서만 가입 가능 → 청년 혜택 1회 적용

**연령별 혜택 구분**

| 혜택 | 대상 연령 |
|---|---|
| 청년 혜택 | 만 18세 ~ 만 39세 |
| 시니어 혜택 | 만 65세 이상 |

| 구분 | 내용 |

| To-Be | 유선도 동일하게 보여질 수 있도록 개선 |

### 중-2. 휴대폰결제 이용동의 해지 시 휴대폰결제 안심통보 자동해지 로직 개발

**배경**

- 휴대폰결제 이용동의 해지 후 재가입하는 고객의 경우, 과거 가입한 휴대폰결제 안심통보의 보호자 정보가 업데이트되지 않아 민원 발생
- 이용동의 해지 시 안심통보를 자동 해지하면, 재가입 시 업데이트된 보호자 정보로 안심통보 가입 가능

**요청 내용**

| 트리거 상품 | 상품코드 | 자동해지 대상 | 상품코드 |
|---|---|---|---|
| 휴대폰결제 이용동의 해지 | NA00004184 | 휴대폰결제 안심통보 | NA00005872 |

### 중-3. IB SIM렌탈 대상 T머니 지급 관련 전산 체크 로직 추가

**1. 현황**

1. SIM렌탈 구매고객 대상 T머니 지급일 경우, [고객요구사항]에 '티', '티거부' 등으로 메모 기재
2. 고객요구사항을 한 번에 조회할 수 있는 화면이 없고 건바이건으로 거래상세내역에서만 확인 가능 (현장에서 데일리 검수가 어려운 상황)
3. 월별 요구사항 메모 추출(CDTS) 후 담당자 엑셀 수기 작업 중

**2. 문제점**

1. T머니 전산 검수 불가로 일단위 T머니 실재고 마감 불가
2. [고객요구사항] 메모는 [여권번호] 기준으로 관리되어, 벌크/복수 건에 대한 정확한 지급 확인 불가

**3. 제안**

전산으로 명확하게 남길 수 있도록 변경(체크박스 or 수량 기재) 및 변경내용에 대한 IB로밍업무처리내역조회 화면 체크로직 추가

1. T머니 지급건에 대한 전산처리 의무화 (신청/정보변경)
2. IB로밍서비스관리 > 상세정보(렌탈테이블) 내 판촉품 지급 체크박스 추가 (벌크건에 대한 개별지급 확인 가능)
   - 위치: 상세정보 > 예약바우처번호 옆 그리드 추가 > 판촉품 Y/N 체크박스 생성
