## 6. 실패에서 배운 점 (발표용 메시지)

1. **한 번 실행으로는 판단할 수 없다.** 같은 코드로 L-1 이 2/7 ↔ 7/7, SC-001 이 2/2 ↔ 0/2 로 흔들렸다 → 3회 반복 · 평균 · 범위로 비교하는 실험 체계를 만들었다.
2. **지표가 문제를 가릴 수 있다.** 노드 정밀도(0.11)는 경로 수에 묶여 SE 판정을 못 보여 줬다 → [변경] 노드 정밀도로 주 지표를 바꿨고(0.95), 운영 문의처럼 [변경] 을 기대하지 않는 케이스는 채점에서 뺐다.
3. **남은 과제는 "보수적 [참조] 판정"이다.** 놓친 노드의 약 70%가 경로에는 있는데 LLM 이 변경 없음으로 봤다. 조건 분기·검증 추가·데이터 등록·화면 전달처럼 "호출만 하는 것처럼 보이는 변경"을 더 잘 짚어야 재현율이 오른다.
4. **데모와 실사용은 다르다.** 실제 API 로 돌려 보니 언어 이탈 · LLM 무응답 · 세션 유실 같은 운영 문제가 나왔다. 품질 지표 밖의 안정성도 따로 점검해야 한다.
