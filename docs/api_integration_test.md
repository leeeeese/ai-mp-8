### 3-1. tos SC-003: 단순 → 상세 분석 요청 → 복잡

> 타사회선 캠페인은 무료 수신거부 번호(1504)를 쓰지 않습니다. 1. 타사회선일 때 메시지 본문 하단 기본 문구를 '수신거부 (번호 직접 입력)'으로 바꿔 주세요. 2. 타사회선 캠페인의 메시지를 등록할 때 '무료 수신거부 등록에 주의해 주시기 바랍니다' 안내 팝업을 띄워 주세요.

| 단계 | 결과 |
|---|---|
| 1차 분석 | **단순** 판정 ("타사회선 조건에 따른 메시지 등록 화면의 기본 문구와 안내 표시 변경"). 근거 50건, 소요 약 5분 |

| | `CTL:CampMsgController.saveMsg` (진입점 2개), `SVC:CampMsgService.saveMsg` (2개), `SQL:MsgScrtMapper.insertMsgScrt` (3개), `TBL:TCP_MSG_SCRT` (6개), `COL:TCP_MSG_SCRT.SCRT_CTT` (6개) |

## 4. 발견 사항

| 구분 | 내용 | 조치 |
|---|---|---|
| 적재 현황 | 검색 시 `TB_BAT` 로 찾으면 테이블보다 컬럼이 먼저 나옴 | 접두어(`TBL:` 등)를 뺀 ID 비교 + 같은 순위면 컬럼을 뒤로 → 반영 |
| 적재 현황 | `data/` 가 git 밖이라 master 대비를 커밋으로 계산할 수 없음 | 적재 시 `:LoadMeta`(소스 파일별 sha1)를 남기고 현재 소스와 비교 → 반영 |
| 백엔드 로그 | 터미널에 HTTP 요청만 보이고 에이전트 진행·오류가 안 보임 | 진행 이벤트 로그 + 분석 실패 traceback 출력 → 반영 |
| 실행 환경 | conda base 의 `python3` 에 uvicorn·neo4j 가 없어 백엔드 실행 실패 | `.venv` 또는 시스템 Python 3.11 경로로 실행 (README) |
| Agent | SC-003 이 1차에서 단순으로 판정됨 (정답 complex). 상세 분석 권장 → 재분석으로 복잡 흐름 진입 | 재분석 흐름은 의도대로 동작. 1차 판정 · 미탐 노드(`TBL:TCP_CMM_CD`, `SQL:CmmCdMapper.selectCdList`)는 Agent 고도화 과제 |
| Agent | L-4 (정답 simple) 에 상세 분석 권장 1건 | 과한 권장. 권장 기준 고도화 과제 |
| API | 세션은 메모리에만 저장 → 서버 재시작 시 사라짐 (KPI 기록은 파일로 남음) | PoC 범위. 운영 전 저장소 필요 |
