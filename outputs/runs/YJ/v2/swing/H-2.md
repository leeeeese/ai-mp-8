# H-2 요금제 개편에 따른 연령별 혜택 상품 신규 개발 (상 / product)

## 입력

> 요금제 개편에 따라 연령별 혜택 상품을 신규 개발해 주세요. 현재는 각 요금상품 기준으로 연령별 가입 가능한 상품을 제한하고 있습니다. 변경 후에는 요금별 가입 가능 연령은 만 19세 미만 / 만 14세 미만 / 만 65세 이상으로 제한하되, 연령별 혜택은 명의당 1회선에 한해 부가상품으로 정의하여 제한합니다. 예) 만 25세 이용자가 3회선 사용 중이면 3회선 모두 가입 가능 요금제에 가입하되, '청년 혜택' 상품은 1개 회선만 가입 가능. 혜택 구분: 청년 혜택 만 18~39세, 시니어 혜택 만 65세 이상.
