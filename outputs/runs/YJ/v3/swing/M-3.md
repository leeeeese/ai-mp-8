# M-3 IB SIM렌탈 대상 T머니 지급 관련 전산 체크 로직 추가 (중 / product)

## 입력

> SIM렌탈 구매고객 대상 T머니 지급 시 현재 [고객요구사항]에 '티', '티거부' 등으로 메모하고 있어 일 단위 T머니 실재고 마감이 불가하고, 메모가 여권번호 기준이라 벌크/복수 건의 정확한 지급 확인이 불가합니다. T머니 지급건에 대한 전산처리를 의무화(신청/정보변경)하고, IB로밍서비스관리 > 상세정보(렌탈테이블) 내 예약바우처번호 옆에 판촉품 지급 Y/N 체크박스를 추가해 벌크건도 개별 지급 확인이 가능하게 해주세요. 변경 내용은 IB로밍업무처리내역조회 화면에서 체크할 수 있어야 합니다.

## 1. Planner (LLM, Few-shot)

- 복잡도: **complex** (정답 complex) — 신규 지급 항목의 화면 입력·건별 저장, 신청/정보변경의 필수처리 검증, 별도 업무처리내역조회 화면의 변경 내용 확인이 함께 필요합니다. 여권번호 기준 메모로는 벌크/복수 건의 지급 확인이 불가능하다는 문제도 있어 개별 건 식별과 저장·조회 경로를 검토해야 합니다.
